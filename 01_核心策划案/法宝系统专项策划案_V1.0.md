## 0. 法宝系统总纲

### 0.1 定位
法宝横跨游戏的两条循环，是战斗和工厂之间的桥梁：

| 循环 | 法宝的作用 |
| :--- | :--- |
| **战斗 / 探索循环** | 控场、阻挡、机动，给防御塔创造输出窗口 |
| **工厂自动化循环** | 解锁替代配方、局部吸煞、搬运施工、无耗材挂机产出 |

### 0.2 统一规则（所有法宝通用）
1. **每件法宝有一种独立资源**（万魂幡 = 魂力，山河社稷图 = 灵韵），资源只来自游戏行为，不能用钱买。
2. **法宝不能凭空提高产线速度、不能替代生产建筑**。工厂功能只能“换配方 / 省搬运 / 局部减负 / 挂机少量产出”。
3. **统一维护**：所有法宝都在 **炼宝台 (BD_156)** 维护，维护材料统一用 **法宝稳脉液 = 稳定液 (MAT_070)**。不为每件法宝单独新增维修资源。
4. **成长用“重”表示**：1 / 3 / 5 / 7 / 10 重为关键节点，中间重数只做小数值提升。
5. **突破材料只用现有物料**：稳定液 (MAT_070)、人造灵石 (MAT_083)、灵石粉 (MAT_103，即“地脉灵砂”)、煞气结晶 (MAT_067)、法宝 (MAT_110) 等，不额外造新物品。

## 1. FAB_001 万魂幡（人皇旗）

### 1.1 主循环
```
击败敌人 → 获得【残魂】(也可作进阶材料)
   → 残魂进入万魂幡，填充魂力槽
   → 玩家选择插幡位置，展开鬼域控制敌群
   → 魂力消耗完，幡自动收拢
   → 继续战斗，或回基地维护（炼宝台 + 稳定液）
```

### 1.2 武器资源

| 资源 | 范围 | 规则 |
| :--- | :--- | :--- |
| **魂力** | 0 ~ 100（3 重起 120） | 来自残魂。鬼域（摄魂域）消耗 **35**，魂幕消耗 **25**，魂役消耗 **25** |
| **魂压（过载）** | 0 ~ 100% | 连续施放技能会升高；**超过 80% 时技能范围缩小 15%** |
| **反噬** | 魂压到 100% 时触发 | 万魂幡**强制收拢**，玩家 **3 秒内不能再次施法** |
| **维护** | — | 在炼宝台 (BD_156) 用稳定液 (MAT_070) 清零魂压、解除反噬。**不另设维修资源** |

### 1.3 战斗功能

#### ① 收魂（被动）
- 装备后，击败敌人时自动吸收附近残魂。
- **残魂不增加攻击力**，只进入魂力槽，作为控场技能的资源。
- 魂力槽满后不再吸收。
- 离开战斗区域后魂力**缓慢衰减**，防止长期囤积后一次性无成本清场。

#### ② 鬼域（主动核心技能）
- 把万魂幡插入地面，生成**半径 8m** 的鬼域，**持续 10 秒**。
- **普通敌人**：移动速度降低，并会优先向幡靠近（聚怪）。
- **精英敌人**：只减速，不被强制拉动。
- **操作**：按住技能键预览圆形范围，松开确认落点；**不能穿墙放置**。
- 技能结束后，万魂幡自动回到玩家手中。

#### ③ 主魂（AI 召唤）
- 消耗魂力召唤一个 AI 辅助战斗。
- 主魂使用**被摄取的目标敌人的行为树**（打死什么敌人，就能召出什么样的主魂）。
- 主魂配置槽：同一时间只能配置 1 个主魂。

### 1.4 工厂功能

#### ④ 配方切换（被动）—— 邪修替代配方
- 正常流程：需要先培养生物细胞，才能得到相关材料。
- 开启配方切换后：可以**直接从敌人尸体上获取替代材料**，减少配方使用的物料种类。
- 当前对应的替代配方（来自 `recipe_table.xlsx` / 古修残卷表）：

| 配方 | 名称 | 效果 |
| :--- | :--- | :--- |
| RCP_175 | 气血丹（练气整尸血炼） | 用练气修士尸体直接炼气血丹 |
| RCP_176 | 破障丹（筑基整尸血炼） | 用筑基修士尸体直接炼破障丹 |
| RCP_177 | 凝丹液（金丹整尸直萃） | 用金丹修士尸体直接萃取凝丹液 |

#### ⑤ 魂力转化 —— 煞气回收
- 把万魂幡插在**煞气回收 / 炼化设施附近**（回收处理塔 BD_150、归墟化煞炉 BD_178），吸收一部分机器排出的煞气，转化为魂力。
- **限制**：只能降低局部污染增长；**不能替代净化塔**；**不能把煞土直接恢复成灵壤**。

#### ⑥ 魂役
- 消耗魂力召出 **2 个短时魂役**。
- 优先级：搬运蓝图施工材料 → 补充附近箱体 → 执行已下达的抢修 / 建造任务。
- **限制**：魂役**不能生成物品**、**不能替代生产建筑**、**不能永久提高产线速度**。

### 1.5 法宝成长（暂定）

| 重数 | 形态 | 魂力上限 | 新增 / 提升 |
| :---: | :--- | :---: | :--- |
| **1 重** | 万魂幡 | 100 | 解锁收魂与鬼域（8m / 10 秒） |
| **3 重** | 万魂幡 | 120 | 鬼域（摄魂域）持续时间 **+2 秒** |
| **5 重** | **人皇旗** | 120 | 解锁**魂幕**；鬼域内普通敌人额外**降低攻击频率** |
| **7 重** | 人皇旗 | 120 | 魂力自然衰减速度降低；鬼域半径提升至 **10m** |
| **10 重** | **人皇旗（冒金光）** | 120 | 解锁【**无尽鬼域**】：鬼域持续 **15 秒**，但结束后魂压**直接提升到 70%** |

**突破材料（暂定，全部为现有物料）**

| 突破 | 材料 |
| :--- | :--- |
| 1 → 3 重 | 稳定液 ×2 + 煞气结晶 ×4 |
| 3 → 5 重 | 稳定液 ×3 + 煞气结晶 ×8 + 法宝 ×1 |
| 5 → 7 重 | 稳定液 ×4 + 人造灵石 ×6 + 法宝 ×1 |
| 7 → 10 重 | 稳定液 ×6 + 人造灵石 ×12 + 法宝 ×2 |

## 2. FAB_002 山河社稷图

### 2.1 资源：灵韵
- **获取**：
  - 行走大地图时收录未被探索的地区（水源、湖泊、山峰、灵脉）自然填充；
  - 移动也能缓慢填充；
  - 也可以放在工厂里**充能**。
- **主循环**：探索地图 → 获取灵韵 → 展开画卷使用功能 → 灵韵耗尽收卷。
- **收卷之后，洞天福地不再生效。**

### 2.2 工厂功能

#### ① 移山填海
- 在大地图上找到矿产，把矿产**收录**进法宝，带回主基地**投影展开**。
- 3 重起解锁，先只允许 1 处基础矿脉（玄铁矿 / 赤铜矿）。

#### ② 洞天福地（无耗材挂机产出）
- 把极品灵植、特殊丹药、高阶灵兽**收录进图里温养**。
- 等于一台**不需要持续输入原料**的机器：
  - 插上 3 朵灵草 → 灵草持续输出物料；
  - 插上 2 只灵兽 → 灵兽持续产出掉落材料。
- **产量增加两倍。**
- 收卷（灵韵耗尽）后停止产出。

#### ③ 升级矿脉
- 消耗灵韵提升已投影矿脉的富集度（具体数值待定）。

### 2.3 战斗功能

#### ① 分割战场【山河障】（主动）
- 展开一道阻挡敌人前进的画卷墙壁（像火墙一样）：
  - **普通敌人无法通行**，被迫绕远路（给防御塔留出超长射击窗口）；
  - **远程怪的子弹射进画卷会被空间吞没**。
- 墙宽：1 重 5m → 3 重 8m → 后续 10m。

#### ② 缩地成寸（特化被动）
- 展开山河图时，在画卷覆盖范围内玩家**移动速度 +50%**。

### 2.4 限制：磨损与休眠
- 每次**阻挡攻击**或**搬迁高阶地脉**，灵韵会下降，并对法宝造成磨损。
- **灵韵降到 0** 时：
  - 法宝进入**休眠**；
  - **不再挂机恢复灵韵**；
  - 必须在**炼宝台**消耗材料修补（稳定液 + 人造灵石 / 灵石粉）。

### 2.5 晋升条件

| 重数 | 灵韵上限 | 战斗 | 工厂 | 晋升条件 |
| :---: | :---: | :--- | :--- | :--- |
| **1 重** | 100 | 解锁【山河障】（**5 米墙**）与【缩地成寸】 | 洞天福地槽位 ×1（可插 1 个灵草 / 灵兽挂机） | 探索大地图任意 **3 个**未收录区域；炼宝台消耗 **灵石 ×10 + 稳脉液 ×1** 突破 |
| **3 重** | 130（移动恢复速度 +20%） | 风墙宽度 **8 米**，持续时间 **+2 秒** | 洞天福地槽位 ×**2**；解锁【移山填海】（收录并投影 1 处基础矿脉，如玄铁矿 / 赤铜矿） | 累计用洞天福地收获 **200 份**材料；收录 **1 处大型水源**；消耗 **地脉灵砂 ×20 + 稳脉液 ×3** 突破 |
| 5 重 | 待定 | 待定（预计墙宽 10 米） | 待定（预计槽位 ×3） | 待定 |
| 7 重 | 待定 | 待定 | 待定 | 待定 |
| 10 重 | 待定 | 待定 | 待定 | 待定 |

> 物料对照：灵石 = 人造灵石 (MAT_083)；地脉灵砂 = 灵石粉 (MAT_103)；稳脉液 = 稳定液 (MAT_070)。

## 4. 新增法宝时的标准字段（模板）
新增法宝时，请按以下字段补全，并同步一行到 `fabao_table.xlsx`：

| 字段 | 说明 |
| :--- | :--- |
| 法宝编号 | FAB_00X |
| 名称 / 进阶形态 | 如“万魂幡 / 人皇旗” |
| 核心资源 | 名称、上限、获取方式、衰减规则 |
| 主循环 | 一句话写清“怎么获得资源 → 怎么花掉” |
| 战斗功能 | 主动 / 被动，数值写清楚 |
| 工厂功能 | 必须遵守总纲第 2 条：不能凭空提速、不能替代生产建筑 |
| 限制 | 过载 / 磨损 / 休眠等 |
| 成长表 | 1 / 3 / 5 / 7 / 10 重 |
| 突破材料 | 只用现有物料 |
