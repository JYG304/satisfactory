# Satisfactory · 修仙工厂

这是一个可直接在浏览器运行的《修仙工厂》HUD / 工厂自动化玩法原型。

## 在线试玩

GitHub Pages：<https://jyg304.github.io/satisfactory/>

## 本地运行

直接打开 `index.html` 即可；如果浏览器限制本地脚本加载，使用任意静态文件服务器启动项目根目录。

## 项目结构

- `index.html`：GitHub Pages 入口，跳转到完整 HUD 原型
- `satisfactory_hud_replica.html`：主游戏原型页面
- `css/`：界面样式
- `js/`：背包、机器、配方、任务、建筑等模块
- `xiuxian_data.js`：游戏数据配置
