# 中央处理器 · 三才光路阵盘系统 (三足鼎立花样布局)

> **设计定位**：修仙工厂核心主脑算力控制中枢，将修仙宗门的三大核心维度（攻击战斗、工业制造、辅助机动）实体化为**三足鼎立 · 三才大阵**（顶峰离火攻击盘、左翼辰土工厂盘、右翼碧水辅助盘、中央三才归元台），通过境界分配环数，依托外圈射出点实现跨盘联动贯通。

---

## 一、三足鼎立 · 三才花样空间布局

彻底颠覆单一单调的水平横线排布，采用道门经典的**三才聚顶阵型**：

```
                    ┌──────────────────────────┐
                    │  ⚔️ 顶峰 · 离火攻击盘    │
                    │  (cx: 720, cy: 195)      │
                    └─────────────▲────────────┘
                                  │ 跨盘高能跃升光束
                                  │
                          ┌───────┴───────┐
                          │  三才归元核心  │
                          │ (cx: 720, 408)│
                          └───────▲───────┘
                                  │
         跨盘水平贯穿光束         │
  ┌────────────────────────┐      │      ┌────────────────────────┐ 始发高能激光
  │  ⚙️ 左翼 · 辰土工厂盘  │◄─────┴──────┤  🛡️ 右翼 · 碧水辅助盘  │◄───────────── [EMITTER 01]
  │  (cx: 380, cy: 515)    │             │  (cx: 1060, cy: 515)   │
  └────────────────────────┘             └────────────────────────┘
```

* **⚔️ 顶峰 · 离火攻击盘 (cx: 720, cy: 195)**：绯红炽焰主题，居高临下主导杀伐爆发、飞剑巡航与暴击破甲。
* **⚙️ 左翼 · 辰土工厂盘 (cx: 380, cy: 515)**：璀璨玄金主题，稳如磐石主导制造加速、开采增效与电耗减免。
* **🛡️ 右翼 · 碧水辅助盘 (cx: 1060, cy: 515)**：苍翠碧霄主题，首接始发高能光路，主导移速护体与飞剑续航。
* **🌀 阵心 · 三才归元共鸣台 (cx: 720, cy: 408)**：三盘全部贯通时，自三盘外圈射出点向中央阵心汇聚激光，触发 **×1.5倍** 全盘终极共鸣倍率！

## 二、境界配比与单选特化规则

每个阵盘均具有 **4 环标准同心轨道**（1环内宿6位、2环中宿8位、3环外宿12位、4环绝顶16位）。玩家根据境界享有环数配比上限，且**只允许单选一个盘作为主特化盘**：

| 修为境界 | 特化规则（单选项三选一） | 主特化盘环数 | 其余两盘环数 | 全盘活跃插槽总数 |
| :--- | :--- | :---: | :---: | :---: |
| **练气期** | 可单选切换：攻击盘特化 / 工厂盘特化 / 辅助盘特化 | **2 环** (14 槽) | **1 环** (6 槽) × 2 | **26 槽** |
| **筑基期** | 可单选切换：攻击盘特化 / 工厂盘特化 / 辅助盘特化 | **3 环** (26 槽) | **2 环** (14 槽) × 2 | **54 槽** |
| **金丹期** | 可单选切换：攻击盘特化 / 工厂盘特化 / 辅助盘特化 | **4 环** (42 槽) | **3 环** (26 槽) × 2 | **94 槽** |

## 三、圆环旋转与「+」功能全面保留

1. **圆盘多维旋转**：
   * **鼠标拖拽旋转**：鼠标按住任意圆盘直接绕圆心平滑拖动旋转。
   * **鼠标滚轮旋转**：鼠标停在哪个环上方转动滚轮，即可灵动旋转对应轨道。
   * **圆环 `[◀ R 环名 ▶]` 步进微调**：每个圆环标签两端内置步进按钮，点击即可轻松步进微调。
2. **极核 `+` 专属插槽**：
   * 三大盘盘心均保留闪烁的 `+` 核心极核插槽，点击直接配置核心特质插件。
3. **绚丽芯片阶梯色彩体系**：
   * 盘面安插芯片绝非单一灰暗色块，全面匹配鲜明饱满的阶梯质感配色：
     * **战斗类芯片**：赤红霓虹渐变（`chip-bg-combat`）
     * **工业类芯片**：玄金琥珀渐变（`chip-bg-industry`）
     * **辅助类芯片**：蔚蓝海潮渐变（`chip-bg-mobility`）
     * **变轨类插件**：幽紫棱镜流光（`chip-bg-shift`）
     * **极核类特质**：翡翠碧玉流光（`chip-bg-keystone`）
