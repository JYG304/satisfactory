# 中央处理器 · 阵盘光路系统设计与实现方案 (Git 归档)

## 一、 系统定位与概述

**中央处理器 (Central Processor Array)** 是修仙自动化工厂的核心总控枢纽。
系统以古代精密天文浑天仪与现代光子集成芯片为灵感，通过**始发高能光束在多重离散同心圆盘与变轨透镜之间的折射、步进、汇聚与闭环**，为整座宗门自动化工厂提供全局工业生产效率与战伐护卫属性加成。

## 三、 步进离散与空间凑数数学机制 (1/2/3/5/8 格)

### 1. 步数合理性设计
阵盘光路摒弃浮点拉线，采用**严格的离散整数步进**：
* 芯片提供固定的顺时针步进数：`+1格`、`+2格`、`+3格`、`+5格`、`+8格`。
* **同一个圆盘内**：每格物理角度 $360^circ / N$ 完全等距，物理弧长绝对均分。
* **空间凑数与背包找零博弈 (Coin Change)**：
  * `+1格` 是万能微调与闭环补缝的基础基石；
  * `+5格` 与 `+8格` 是大跨度跨越工具；
  * 玩家可通过组合（如 $8 + 5 + 3 = 16$ 或 $5 + 5 + 5 + 1 = 16$）在 16 槽天盘上以极少的插槽代价完成单圈闭合，留出更多空槽安装高级属性芯片。

### 2. 光路物理不自交规制
* 芯片在盘面顺时针步进时，以**圆盘同心步进弧线**呈现。
* 当光线经向心变轨镜汇聚至盘心极核后，通过**盘底潜行导流暗渠**引至圆盘外边缘的**准直喷嘴**发射，绝不横穿盘面切割其他芯片。

## 四、 底盘星象全满倍增规则 (×1.2 倍全属性)

底盘可选 6 种经典修仙星象：
1. **北斗七星天衡阵**：共 7 处星宿节点（天枢、天璇、天玑、天权、玉衡、开阳、摇光）。
2. **南斗六司延寿阵**：共 6 处星宿节点。
3. **紫微帝垣万剑阵**：共 5 处星宿节点。
4. **二十八宿四象阵**：共 4 处极点节点。
5. **九曜日月行天阵**：共 9 处星宿节点。
6. **天罡雷劫破虚阵**：共 8 处雷劫节点。

### 全满触发机制
* 光路途经底盘星宿节点时，该节点被点亮并记录；
* **当光路贯通并满足当前星象的所有插槽时**（如北斗七星 7/7 槽全满足），**整个中央处理器的全部输出属性实时获得 ×1.2 倍加成**！
* 动力看板直白清晰显示达成进度（`7/7 全插槽满足 ➔ 生效 x1.2`）。

## 六、 交互控制指南

1. **安装构件/插件**：从左侧抽屉（点击悬浮挂钮拉出）拖拽任意芯片至盘面空插槽即可吸附安装。
2. **取回构件/插件**：鼠标【右键】点击盘面任意已装配芯片或盘心核心，即可瞬间取回。
3. **圆盘无极拖拽旋转**：鼠标左键按住任意圆盘（包括未装芯片的空插槽）平滑拖拽，圆盘丝滑随动。
4. **鼠标滚轮顺畅微调**：鼠标指针悬停在任意圆盘区域，**滚动滚轮**即可快速以标准步距顺时针/逆时针微调旋转角度。
5. **动力看板查看**：点击右侧悬浮挂钮展开看板，直白查看工业生产、战伐输出、阵地防御总加成及星象满足状态。
