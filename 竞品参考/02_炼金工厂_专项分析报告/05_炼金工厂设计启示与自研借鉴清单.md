# 05｜《炼金工厂》设计启示与自研借鉴清单

> [!NOTE]
> 如果你的团队正在研发**“魔幻/修仙 + 工厂自动化 + 店铺经营”**复合品类游戏（例如修仙工厂、魔法工坊、奇幻自动化沙盒），《炼金工厂》提供了大量比传统科幻工厂更贴合题材的设计范式。

---

## 一、 6 大可复用的核心设计模板

### 1. 用“实体货币 + 商业许可”替代枯燥的科研点数
* **炼金工厂做法**：不设纯消耗性的“科研糖块”，而是让玩家把工厂产物摆上货架卖给顾客，获得**实体硬币**；硬币本身可以走传送带自动塞进“进货传送门”买原料，形成**“造货 → 卖货 → 吐币 → 买料 → 扩产”**的商业正反馈。
* **自研借鉴**：修仙/魔幻题材天然适合“坊市开店、宗门供奉、灵石实体化”，用商业营业执照（许可等级）卡阶段比纯科技树更有代入感。

### 2. “种子不消耗 + 肥力驱动产速”的自动化农业模板
* **炼金工厂做法**：魔法苗圃放入种子后永久保留，仅消耗肥料的营养值（维塔 V），且肥料品质直接决定作物生长速度。
* **自研借鉴**：极大降低了自动化农田的种子回流逻辑复杂度（玩家无需担心“种子用光断链”），非常适合灵草种植、炼丹原料量产。

### 3. “热能底座”替代现代电网
* **炼金工厂做法**：需要加热的炼金炉/熔炉必须直接架在加热设施上方，省去了拉电线杆的现代工业违和感，又保留了“燃料供应与能量布局”的策略深度。
* **自研借鉴**：在修仙/中世纪题材中，可用**“灵脉阵眼 / 地火炉灶”**作为底部供能基座，既符合世界观又自然限制了厂房排布。

### 4. “物理抛射 + 弹跳接力”的趣味立体物流
* **炼金工厂做法**：除了常规传送带，允许用投掷器/大炮直接往敞口锅/货架里抛射物品，配合弹跳菇实现跨地形空中接力。
* **自研借鉴**：在第一人称或立体 3D 工厂中，抛射物流能带来极强的观赏性与物理趣味性，同时缓解多层建筑穿墙拉带的视觉杂乱。

### 5. “催化剂四维杠杆”提升炼金深度
* **炼金工厂做法**：炼金炉内置 4 种催化剂维度——`翻倍产出(Fertile)`、`全产物必出(Resonant)`、`改写概率(Unstable)`、`不消耗材料(Eternal)`。
* **自研借鉴**：相比单纯的“+25% 增产”，在丹药/炼金系统中加入“保底出副产”“改写暴击概率”“省主材”等催化剂，能显著放大题材特色。

### 6. “B2C 门店零售 × B2B 发货传送门合同”双出口
* **炼金工厂做法**：前期靠门店货架零售赚高毛利，后期大宗量产通过“发货传送门”按低于市场价走供应合同，避免后期商品卖不出去或货架补货手忙脚乱。
* **自研借鉴**：一定要为后期爆产能的玩家提供**大宗批量倾销出口**（如宗门大宗采购/商队传送阵），否则门店客流量会成为后期产线扩张的死锁瓶颈。

---

## 二、 5 大避坑清单

1. **切忌让店铺声望惩罚过重**：炼金工厂通过“货架被堵高亮提示 + 允许随时关店调整”避免了玩家在装修产线时莫名掉声望，自研时务必提供“一键歇业/暂停营业”开关。
2. **明确区分“无法上带”的特殊道具**：如格纳胶（`GelatinousGridlock`）故意设计为不能上传送带，专门用于占格子防混料；此类特殊规则必须在 Tooltip 中明示。
3. **尽早给出“自动化收银”与“通宵营业”解锁**：前期手动收银和夜晚强制关店能建立开店仪式感，但必须在中期（T2 左右）迅速提供自动收银机与减睡眠道具，避免重复劳动疲劳。
4. **控制矿车逻辑过滤的上手门槛**：颜色 + 前缀标签（`AA.BB`）+ 与/或/非过滤非常强大，但需要内置清晰的图文手册与预设模板。
5. **开放自由变形/建造辅助视角**：第一人称建厂在多层立体空间中容易卡视角或够不着高处，除了飞行/搭脚手架外，类似“范围框选 + 蓝图复制 + 变小钻缝”能大幅提升操作上限。
