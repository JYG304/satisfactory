# 《炼金工厂》(Alchemy Factory) 专项分析报告资料包

本资料包基于《炼金工厂》（UE 5.6）底层 **56 张 DataTable** 与 **全量中文文本库 (`zh_loc.json`)** 解包整理，所有报告均采用相对路径引用 `./data/` 下的结构化表格，可直接整包复制到其他电脑使用。

---

## 目录结构

```text
炼金工厂_专项分析报告/
├── README.md                                  # 本总览与阅读导航
├── 01_产品定位_核心玩法循环与系统架构分析.md     # 产品定位、生产×零售×金融双核循环、8大特色机制、竞品对比
├── 02_全建筑设施_物流系统与机械机制手册.md       # 全量 147 项建筑/设施/结构件分类清单与官方功能说明
├── 03_全物品经济_163配方树与炼金产线深度分析.md   # 全量 163 配方明细、阶位产出效率、农业/炼金/终极产线剖析
├── 04_成长解锁_科技树_许可与商业经营系统拆解.md   # 营业许可、科技改进、技能点、顾客购买曲线、贷款与合同系统
├── 05_炼金工厂设计启示与自研借鉴清单.md           # 6大可复用设计模板 + 5大避坑清单
└── data/                                      # 解包后的结构化数据（Excel 可直接打开 CSV）
    ├── alchemy_recipes.csv                    # 163 个配方完整表（含耗时、每分钟产出、输入输出）
    ├── recipes_parsed.json                    # 原始解析配方 JSON
    ├── alchemy_buildings.csv / .json          # 147 项建筑与结构件中英文对照及说明
    ├── alchemy_items.csv / .json              # 188 种物品中英文对照及描述
    ├── alchemy_manuals_zh.json                # 65 条官方说明书、催化剂与提示文本
    ├── alchemy_datatables_summary.json        # 56 张 UE5.6 DataTable 的 NameMap 与字节统计
    └── zh_loc.json                            # 完整中文多命名空间本地化库
```

---

## 按角色推荐阅读顺序

- **制作人 / 立项**：`01`（定位与循环） → `05`（设计启示与避坑）
- **系统 / 商业策划**：`01` → `04`（许可/顾客/贷款/合同） → `02`（建筑与物流）
- **数值 / 经济策划**：`03`（163 配方树与产线） → `data/alchemy_recipes.csv` & `data/alchemy_items.csv`
