# 05｜工厂自动化游戏自研设计启示与避坑清单

> [!NOTE]
> 本篇从游戏制作人与系统策划视角出发，提炼《戴森球计划》中可直接复用于自研自动化/工厂游戏（如修仙工厂、2D/3D 自动化沙盒）的 **6 大核心设计模板** 与 **8 大常见避坑清单**。

---

## 一、 可直接复用的 6 大核心设计模板

### 1. 传送带与配方节拍的“整数倍离散设计”
* **DSP 做法**：矿机采集 `0.5/s`，熔炉基础耗时 `1.0s`，传送带三档速度为 `6/s`、`12/s`、`30/s`（倍率 `×2` 与 `×2.5`）。
* **设计收益**：1 条基础带恰好吃满 12 台采矿机或 6 台熔炉；玩家**不需要打开外部计算器**，仅凭心算就能做出 100% 满载、不堵带的模块化产线。
* **自研建议**：切忌把传送带速度和配方时间设计成带小数的非整数倍（如 7/s 传送带配 1.3s 熔炉），否则会大幅提高普通玩家的心智负担。

### 2. 建筑速度倍率梯度（压迫感 → 基准 → 爽感）
* **DSP 做法**：制造台速度设计为 `0.75x (Mk.I) → 1.0x (Mk.II) → 1.5x (Mk.III) → 3.0x (黑雾重组台)`；熔炉为 `1.0x → 2.0x → 4.0x`。
* **设计收益**：初期用 0.75x 制造“刚好有点慢”的轻微产能焦虑，中期用 1.0x 降低计算心智，后期用 3.0x/4.0x 提供极大的“旧产线原地升级后产能暴涨”的爽快感。

### 3. “发布-订阅”网络化物流（终结后期拉带噩梦）
* **DSP 做法**：中期（黄糖）解锁行星内/星际物流运输站（PLS/ILS），用“本地/远程 供应-需求”槽位取代长距离传送带。
* **设计收益**：彻底将玩家从重复铺设跨地图传送带的体力劳动中解放出来，让玩家把精力集中在“配方搭配、蓝图优化与星际扩张”上。

### 4. 多产物联产与“双向平衡调节阀”
* **DSP 做法**：原油精炼同时产出 `精炼油 + 氢`，任意一种堵死整条线停摆；但同时提供“火电烧掉多余燃料”以及“X射线裂解 / 重整精炼”双向转化配方。
* **设计收益**：既制造了有深度的物流/化工谜题（区别于简单的 A+B=C），又给了玩家多种合法的解题出口，不会变成无解死锁。

### 5. 珍奇资源的“产线跳级”而非“硬卡关锁”
* **DSP 做法**：外星系的 7 种珍奇矿物（如可燃冰、刺笋结晶、光栅石）都不是通关必需品，但能将 4~5 步复杂化工简化为 1~2 步。
* **设计收益**：普通玩家窝在母星也能通关，硬核玩家有极强动力去探索高风险/远距离区域，实现“探索激励”与“保底体验”的双赢。

### 6. 实体化的“终极视觉奇观”目标
* **DSP 做法**：玩家不是为了在 UI 上凑齐某个数字而玩，而是亲眼看着太阳帆织成光环、火箭飞向恒星焊接成遮天蔽日的戴森球。
* **设计收益**：将枯燥的“吞吐量数字增长”转化为极具震撼力的 **3D 空间视觉奇观**，是长线留存与口碑传播的最大引擎。

## 二、 自研工厂游戏 8 大避坑清单

| 常见坑点 | 问题表现与玩家流失原因 | DSP 的教训 / 推荐解法 |
| :--- | :--- | :--- |
| **1. 手搓期过长或过短** | 过长导致像在玩点击器；过短则缺乏“从零建立自动化”的对比爽感 | 保持 **10~15 分钟手搓过渡**，在 T0/T1 迅速给出自动化采矿机、熔炉与初级研究站 |
| **2. 跨阶段过渡断层（如搬钛痛点）** | 新资源解锁了，但自动跨区物流还没解锁，迫使玩家反复人肉跑腿 | 当强制要求跨区域采集某种新资源时，应**同步或提前半步**解锁基础自动运输工具 |
| **3. 副产物死锁无提示** | 玩家不理解为什么整条产线突然停机，排查半天才发现是一个副产物箱子满了 | 增加明确的**“输出堵塞/副产物满溢”视觉告警**，并在前期就引导消纳出口（如焚烧炉/转化配方） |
| **4. 电力崩盘导致“死亡螺旋”** | 电网过载降频 → 煤矿采矿机变慢 → 发电量进一步暴跌 → 全图停电无法重启 | 1) 保留不依赖燃料的保底电源（如风电）<br>2) 允许**独立电网或优先保供采矿/发电侧电路** |
| **5. 战斗系统强行打断建造心流** | 前期玩家正在专心算配方，突然刷怪拆家，挫败感极强 | 1) 允许开局自定义关闭/调节敌人强度<br>2) 威胁度与玩家自身产能/电力挂钩<br>3) 提供**自动维修+自动拾取基站**减少后期救火 |
| **6. 无损升级与批量拆除缺失** | 升一级建筑就要拆掉重摆，导致玩家干脆放弃优化旧产线 | 必须从第一天就支持**同类型建筑原地覆盖升级**、连续拖拽铺设与区域框选蓝图 |
| **7. 网格畸变导致蓝图失效** | 球面或特殊地形导致同一套蓝图换个位置就放不下 | 若非强需求真实球面，自研项目建议优先采用**平面正交网格（或分段独立区域网格）**，大幅降低蓝图对齐成本 |
| **8. 后期缺乏“无限消耗黑洞”** | 通关瞬间所有产线失去意义，玩家立刻弃坑 | 设计**无限递进科技**（如矿物利用、产能倍率、探索效率）与宏大外观奇观作为长期产出黑洞 |
