# 《戴森球计划》(Dyson Sphere Program) 专项分析报告资料包

本文件夹为**完整版、自包含、可跨电脑直接复制**的《戴森球计划》深度分析资料库。所有报告内的图表与数据文件均采用**相对路径**引用，将整个 `戴森球计划_专项分析报告` 文件夹复制到任意电脑即可完整阅读。

---

## 目录结构

```text

├── 02_科技树_经济数值与能源跃迁深度分析.md       # T0-T6 科技树、315项科技统计、燃料热值跃迁、珍奇矿杠杆、增产剂复利、终极产线链
├── 03_物流_机甲_战斗与UX交互系统拆解.md          # 6层物流演进、伊卡洛斯机甲成长、黑雾战斗与逆向科技闭环、球面UX减负
├── 04_全建筑与核心配方数值参考手册.md            # 全建筑性能清单 + 冶炼/化工/机电电子/戴森/对撞科研核心配方表
├── 05_工厂自动化游戏自研设计启示与避坑清单.md     # 6大可复用设计模板 + 8大工厂游戏避坑清单
```

## 按角色推荐阅读顺序

- **制作人 / 立项评估**：`01`（定位与竞品） → `05`（设计启示与避坑）
- **系统 / 战斗策划**：`01` → `03`（物流/机甲/黑雾/UX） → `05`
- **数值 / 经济策划**：`02`（科技/能源/珍奇矿/增产剂） → `04`（全建筑与配方手册） → `data/*.csv`

---

## 跨电脑阅读工具建议

1. **Markdown 报告（`01_`–`05_`）**：推荐使用 **Typora**、**Obsidian** 或 **VS Code**（安装 Markdown Preview Enhanced / Mermaid 插件）打开，可完整渲染文中的 **Mermaid 流程图**、数学公式与表格。
2. **数值明细表（`data/*.csv`）**：可直接使用 **Excel** 或 **WPS 表格** 打开筛选与二次计算；`.json` 文件适合配合 Python 脚本读取。
3. **复制注意事项**：请保留整个 `戴森球计划_专项分析报告` 文件夹的完整层级结构，勿单独抽出 `.md` 文件，以确保相对路径链接（`./data/...`）正常生效。
