# 03｜物流、机甲、战斗与 UX 交互系统拆解

> [!NOTE]
> 本文档深度拆解《戴森球计划》的四大核心系统支柱：6 层物流网络演进、伊卡洛斯机甲成长线、《黑雾崛起》战斗与逆向科技闭环、以及球面建厂 UX 工程减负设计。

---

## 一、 6 层物流系统演进架构

工厂游戏的本质是**“空间搬运与时间节拍的调度”**。DSP 通过 6 个层级的物流工具，精准匹配不同规模的生产阶段，彻底解决了传统工厂游戏后期“传送带打结、难以扩展”的通病：

```mermaid
flowchart LR
    L1["1. 产线毛细血管<br>传送带 (6/12/30/s) + 分拣器"] --> L2["2. 局部交叉与高密<br>四向分流器 + 自动集装机 (堆叠4层→120/s)"]
    L2 --> L3["3. 小规模补给/机甲配送<br>物流配送器 (箱顶10机, 补给/末端分拣)"]
    L3 --> L4["4. 单星干线枢纽<br>行星内物流运输站 PLS (3槽x5000, 50运输机)"]
    L4 --> L5["5. 跨星/跨恒星骨干网<br>星际物流运输站 ILS (5槽x10000, 10运输船+翘曲)"]
    L5 --> L6["6. 气态巨星无限采掘<br>轨道采集器 (自供能无限抽氢/重氢/可燃冰)"]
```

### 1. 微观产线层：传送带、分拣器与集装堆叠
- **分拣器（Sorter）的独特设计**：不同于《异星工厂》机械臂固定 1 格抓取，DSP 的分拣器支持 **1~3 格跨带抓取**，代价是抓取距离越长速度越慢（如基础分拣器 1 格 1.5/s、2 格 0.75/s、3 格 0.5/s），鼓励玩家设计紧凑产线。
- **自动集装机 & 集装分拣器**：允许将传送带上的货物垂直堆叠最多 **4 层**，使极速传送带（30/s）的等效通量瞬间翻 4 倍达到 **120 个/秒**，在不增加新传送带等级的前提下直接突破后期吞吐瓶颈。

### 2. 宏观网络层：PLS / ILS 的“发布-订阅”范式
- **行星内物流站 (PLS)** 与 **星际物流站 (ILS)** 允许为每个槽位独立设置 `本地供应 / 本地需求 / 本地仓储` 与 `星际供应 / 星际需求 / 星际仓储`。
- **架构意义**：玩家在设计新产线时，只需“放一个物流塔 → 拉几条短带进黑盒产线 → 再拉回物流塔”，完全不需要关心原料来自星球背面还是 20 光年外的另一个星系。这种设计将全图物流复杂度从 **$O(N^2)$ 点对点连线** 降维为 **$O(N)$ 节点注册**。

## 二、 伊卡洛斯（Icarus）机甲成长体系

玩家操控的机甲“伊卡洛斯”并非单纯的摄像机载体，而是一个集**移动工厂、建造平台、能源核心与星际战舰**于一体的可成长角色：

| 成长维度 | 对应升级科技（解包数据） | 核心体验变化 |
| :--- | :--- | :--- |
| **能源续航** | `机甲核心 (6级)`、`能量回路 (6级)` | 提升机甲内置反应堆容量与无线充电接收功率，支持从烧煤过渡到内置反物质/奇异湮灭棒“永动” |
| **建造效率** | `无人机引擎 (6级)`、`批量建造 (6级)`、`通讯控制 (7级)` | 建造无人机数量、飞行速度与建造范围大幅提升，实现数百个建筑的蓝图“秒级铺设” |
| **移动与星际航行** | `驱动引擎 (6级)`、`机舱容量 (7级)` | 解锁地面加速 → 星球飞行 → 脱离行星引力 → 曲率引擎（跨恒星光速巡航） |
| **战斗与生存** | `能量护盾 (7级)`、`结构强化 (6级)`、`地面/太空编队扩容 (各7级)` | 机甲从纯建造工具进化为可携带战斗无人机编队、手动清除地面与太空黑雾据点的战力核心 |

## 三、 《黑雾崛起》战斗与逆向科技闭环

早期 DSP 是纯和平建造游戏，后期加入了《黑雾崛起》(Rise of the Dark Fog) 战斗系统，其最巧妙之处在于**“战斗不是纯粹的消耗负担，而是解锁终极工业建筑的唯一钥匙”**：

### 1. 威胁度驱动机制（电力 & 算力）
* 黑雾分为 **行星地面据点（中继站供能）** 与 **轨道太空巢穴**。
* 玩家工厂的**耗电量与戴森球建设规模**直接推高黑雾威胁度，触发地面机械部队波次进攻或太空巢穴的轨道轰炸，将“工业扩张”与“防御需求”自然绑定。

### 2. 立体防御与自动后勤体系
根据 [dsp_machines.csv](./data/dsp_machines.csv) 解包数据，DSP 的防卫系统形成了极高自动化程度的协同矩阵：
* **点防与面防结合**：高斯机枪塔（低成本消耗弹药）+ 高频激光塔（纯电力驱动、零弹药后勤）+ 聚爆加农炮（重型范围破甲）+ 干扰塔（减速+破盾）。
* **超视距制导与全球防空**：**信号塔**（45m 侦测）为 **导弹防御塔** 提供全图激光制导实现超视距打击；**行星护盾发生器** 组网形成全球天幕，抵挡太空黑雾母舰的轨道激光与流星轰炸。
* **零人工维护（核心减负）**：**战场分析基站 (ID: 3009)** 自动派出无人机打捞战场残骸与掉落物并送入传送带，同时自动修复半径内受损建筑与自动补建被毁设施，避免玩家沦为“全图救火队员”。

### 3. 战斗反哺工业（逆向科技闭环）
黑雾单位被击杀后掉落专属稀有材料（如黑雾矩阵、能量碎片、负熵奇点、物质重组器、硅基神经元、核心素），用于解锁并建造游戏内性能最恐怖的终极设备：
* **负熵熔炉 (4.0x)**：速度是电弧熔炉的 4 倍、位面熔炉的 2 倍。
* **重组式制造台 (3.0x)**：速度是制造台 Mk.III 的 2 倍。
* **自演化研究站 (3.0x)**：科研与矩阵合成速度达到普通研究站的 3 倍。
* **奇异湮灭燃料棒 (72,000 MJ)**：10 倍于反物质燃料棒的终极能源。

## 四、 球面建厂 UX 与工程减负设计

在 3D 球面上建造正交网格工厂是极高难度的工程挑战，DSP 团队通过一系列精巧的 UX 设计化解了球面畸变带来的挫败感：

1. **回归线分段网格（Tropic Stepping）**：由于球体越往两极纬线越短，DSP 将行星表面按纬度划分为多个带区，每跨过一道“回归线”网格数量按整数阶梯缩减（如 1000 → 800 → 600...），保证了**同一个纬带内格子依然保持近似矩形**，使模块化产线在赤道与中低纬度几乎无痛对齐。
2. **立体自由拉带与自动立交**：传送带支持按 `↑ / ↓` 键自由抬升高度（每格 1 层），遇到交叉传送带时可自动生成立体跨桥，彻底消除平面游戏常见的“地下传送带长度限制”烦恼。
3. **无损原地升级与批量框选**：低级传送带、分拣器、熔炉、制造台均可直接用高级建筑“覆盖升级”，无需拆除重建；分拣器与传送带支持整条链路的批量升级或拆除。
4. **蓝图与黑盒生态**：支持自定义框选任意产线生成蓝图字符串，支持跨星球复制粘贴，配合“垂直堆叠研究站/储物仓/储液罐”大幅压缩地面占地。
5. **生产统计面板（Statistics）**：提供按“最近 1 分钟 / 10 分钟 / 1 小时 / 10 小时”以及“全星系 / 单行星”维度的实时产出-消耗对比，帮助玩家快速定位产线瓶颈。
