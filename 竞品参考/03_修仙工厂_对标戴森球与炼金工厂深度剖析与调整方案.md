## 第三章：制作人视角剖析（Producer Perspective）—— 10 大系统级欠缺

### 3.1 【经济出口欠缺】唯一“只进不出”的虚拟科研币，导致后期产能失去意义
* **《炼金工厂》的解法**：铜/银/金币是**真实能放在传送带上流转的实体货物**。门店 5 类顾客（平民、士兵、僧侣、商人、贵族）按不同购买力曲线买货 → 自动收银机吐币走传送带 → 进货传送门自动把硬币兑换成基础矿石木材；同时解锁供应合同走发货传送门 B2B 批发出货，形成**生产×零售×金融（贷款杠杆）**铁三角。
* **《戴森球计划》的解法**：虽然没有商店，但有 **6 色实体科研矩阵** 源源不断喂给 206 项升级与无限科技，加上每秒海量 **太阳帆与运载火箭** 射向恒星。
* **我们的欠缺**：我们只有一个不可上带的 `MAT_020 解析数据`（`form: 数字货币`）。96 个科技节点总消耗不过几千点解析数据，一旦解完，整个世界所有多余丹药、法宝、灵草、兽肉**全部变成只能进焚毁井烧掉的垃圾**。

### 3.2 【机器世代欠缺】全游戏 `1.0x` 单速率时代，缺乏“原地覆盖升级”爽点
* 《戴森球计划》仅凭 `电弧熔炉(1x) → 位面熔炉(2x) → 负熵熔炉(4x)` 与 `制造台 Mk.I(0.75x) → Mk.II(1x) → Mk.III(1.5x) → 重组台(3x)`，就让玩家在 T2、T4、T6 经历了三次全厂产线升级潮。
* 《炼金工厂》也明确区分了 `Alembic → AdvancedAlembic`、`Athanor → AdvancedAthanor`、`Cauldron → AdvancedCauldron`、`Blender → AdvancedBlender`、`Grinder → EnhancedGrinder(2x)`、`Assembler → Omni-Machine(3带入+1管入)`。
* **我们的欠缺**：玩家从第 1 分钟用到大结局的是同一台 `精炼炉`、`采矿机`、`培养仓`、`组装机`，后半程没有**建筑换代更新的养成快感**。

### 3.3 【物流维度欠缺】练气期一步给透，中后期既无“趣味抛射/铁路”，又无“塔式发布订阅”
* **横向缺趣味（对比《炼金工厂》）**：练气期就解锁了智能分/合流与限速器；但缺少《炼金工厂》极其吸睛且适配短视频传播的 **投掷器/加农炮+弹跳菇空中跨谷接力**、**矿车轨道系统（颜色 + 前缀 `AA.BB` + `与/或/非` 逻辑分流）** 与 **垂直载物货梯**。
* **纵向缺减负（对比《戴森球计划》）**：传送带全游戏只有一种速率，没有 `6/s → 12/s → 30/s` 的代差提速，没有 `自动集装机` 将带面物料叠 4 层实现 `120/s` 超高密传输，也没有像 **PLS/ILS 物流塔** 那样让玩家只需设置“供应/需求槽位”就彻底告别跨全图拉带子的痛苦。只有元婴期才给一对点对点 `跨区传送门`，远远不够。

### 3.4 【二次改造杠杆欠缺】增产与催化停留在“UI 全局面板”，没进传送带和机器端口
* **《戴森球》增产剂**：`Mk.I(+12.5%) → Mk.II(+20%) → Mk.III(+25%)` 需要专门产线造增产剂，再拉带送进每一排机器入口前的 **喷涂机**，触发 `1.25^N` 复利或 `+100%` 加速（功耗暴涨 `150%`）。
* **《炼金》四维催化剂 + 多出口败丹**：高阶炼金炉有 2~3 个传送带出口（把失败产物/副产自动分走），同时配合 `Fertile(翻倍)`、`Resonant(全产物必出)`、`Unstable(改概率)`、`Eternal(免材料)` 四种消耗充能型催化剂。
* **我们的现状**：`ShaqiSystem` 和 `OpticalArrayHUD` 是非常好的系统，但在表现层上是全局开关，**玩家不需要为此调整任何传送带布局**。如果增设**带旁注灵喷涂机**和**丹炉多出口+丹引催化剂槽**，中后期每一条老产线都值得再翻修一遍。

### 3.5 【能源与立体空间策略不足】热值只差 3 档，缺高空/堆叠三维机制
* 《戴森球》从风电 `300kW` 一路跃升至微聚变 `15MW`、射线接收 `240MW`、人造恒星 `144MW`，燃料热值更是跨越 `144,000 倍`，还有 **能量枢纽+蓄电器跨星运电** 玩法。
* 《炼金》靠 **`StackableCrucible`（堆叠向上传热）** 与 **`ThermalExtractor`（建得越高产量越大）**，直接奖励玩家把工坊往高空盖。
* 我们目前有极佳的雏形 **`BD_147 灵力引擎（下）` 双热槽设计**，却只停在 `1 层双插槽`，既不能多层堆叠导热，金丹后也没有聚变堆、仙光接收台、人造仙阳炉和跨区储能运电。

### 3.6 【成长维度过于单一】缺少多轨成长带来的微操节奏感
* 目前 96 节点科技树承担了一切解锁，既没有像《炼金工厂》那样拆出 **商业经营许可线 + 玩家背包/建工具/通宵腰带线**，也没有像《戴森球》那样把 **机甲建造速度/飞行/背包/带叠加/矿物保存率** 拆成升级/无限科技。

### 3.7 【节拍数学未与传送带对齐】心算障碍影响硬核工厂玩家手感
* 当传送带速度和核心机器周期不成整倍数时，工厂玩家只能自己套公式。像 `8s / 25s / 35s / 45s / 55s / 75s / 100s` 这些占当前配方近 `38%` 的耗时应当向 `2s / 3s / 4s / 5s / 6s / 10s / 12s / 15s / 20s / 30s / 60s` 对齐。

### 3.8 【中后期战斗与修塔运维未闭环】缺少自动化战场基站与高阶天魔掉落
* 筑基有练气尸体、金丹有筑基/金丹尸体，但**元婴期、化神期零新敌对单位**，也没有类似《戴森球》**战场分析基站**的设施来自动派出傀儡修塔和拾取尸体上带，更没有高阶魔核解锁 `4x 终极神机` 的终极战利品诱因。

### 3.9 【终局破界视觉奇观缺席】把“大千飞升”收缩成了一次 60s 机器合成
* 全剧最高潮“从小千世界跨越飞升至大千世界”，目前仅体现为 `BD_157 渡劫台` 消耗 `人造化神×1+法宝×2+燃料棒×4+重水×4` 输出 `飞升道果×1`。对比《戴森球》满天发射太阳帆与火箭拼出包覆恒星的光球，视觉与情绪落差太大。

### 3.10 【工程级 UX 减负缺口】多代升级、蓝图与全局看板前置设计需同步补齐
* 对标两大竞品的 `05_避坑清单`：一旦进入多代机器换代（`Mk.I → Mk.II → Mk.III`）与大规模产线重构，游戏必须配套**同系建筑原地无损覆盖升级**、**带速无缝替换**、**自动立体跨桥拉带**，以及类似 DSP 的 **分分钟产能-消耗缺料告警统计看板**。

## 第五章：改造底线——必须守住的 4 大独有护城河

在吸收两款竞品长板时，必须把《修仙工厂》已经建立起来的 4 项差异化王牌保留并放大：
